# Local images folder

The sample data uses online photos from Unsplash. If an online photo cannot be
loaded (no internet, link removed), `script.js` automatically shows a built-in
"Image not available" placeholder, so the layout never breaks.

## Using your own photos

1. Copy a photo (for example `my-flat.jpg`) into this folder: `static/images/`
2. When adding or editing a property, type this in the **Image URL** box:

       /static/images/my-flat.jpg

3. Save the property. The image will now load from your own computer.

## Tips

- Use `.jpg`, `.png` or `.webp` files.
- Keep each file under 1 MB so pages load quickly.
- Landscape photos (around 1200 x 750 pixels) look best on the property cards.
- Only use photos you own or that are free to use.
